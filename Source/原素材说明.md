# 复古手账经营游戏素材包 V1

本资源包根据当前对话中生成的图片裁切整理，不是重新绘制的高清生产原稿。

## 包含内容
- `Sprites/JournalPages/`：24 张可书写的复古内页，每张独立 PNG，中心保留留白。可作为手账编辑界面的底图、可售商品、DIY素材。
- `Sprites/TapeCatalog/Vintage/`：16 张复古胶带**商品展示卡**（保留静物背景和文字）。
- `Sprites/TapeCatalog/Pastel/`：16 张浅色胶带**商品展示卡**（保留背景和文字）。
- `Sprites/TapePhotos/`：5 张高清胶带整卷与展开图，用于商店横幅和详情页。
- `Data/items.json` 和 `items.csv`：商品 ID、名称、价格占位、稀有度、路径和图片尺寸。
- `Previews/`：资产总览缩略图。

## Unity 导入
1. 解压后把 `Sprites` 文件夹复制到 Unity 项目的 `Assets/Art/Stationery/` 目录。
2. Unity 中选中 PNG，将 Texture Type 设为 `Sprite (2D and UI)`，必要时调节 Max Size；有文字的商品展示卡建议关闭压缩或使用较高质量压缩。
3. 内页建议在 Canvas -> Image 上使用；可叠加 TMP Input Field 或文字/UI贴纸，**文字是独立对象**，不要写入底图。
4. 商店的商品卡显示 `TapeCatalog` 图片；点击购买后可用商品 ID 加入玩家库存。
5. `Data/items.json` 可作为商品表原型，但 Unity 原生 JsonUtility 不方便直接处理任意 JSON 结构，建议先转 ScriptableObject 或实现可序列化列表类。

## 已知限制与后续美术生产
- 胶带卡片是从多宫格图中裁切出来的，**不是透明背景的独立胶带卷 3D/2D 精灵**，不能直接拿来做拖拽胶带贴纸。
- “一循环”图案只是图像展示，没有严格可平铺的无缝重复周期；真正的手账拖拽/撕胶带玩法还需要制作透明的、可平铺的长条贴图。
- 该批素材的分辨率源于生成图片，内页每张约 210×300 像素，放大时会损失清晰度；适合 UI 原型和低分辨率 Demo，不宜直接用于印刷或高分辨率商业上线。
- 图片中可能存在不可读或错误的装饰性文字，不适合作为真实邮票/历史文件等准确复刻。
- 定价均为示例的**游戏金币**，并非现实商品价格。

## MVP 玩法建议
从“选择内页 → 添加胶带商品 → 编辑文字 → 保存手账作品 → 消耗金币 / 解锁新图案”的单机循环开始；暂不接入支付和物流。

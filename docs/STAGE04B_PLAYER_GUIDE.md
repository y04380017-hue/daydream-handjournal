# Stage 04-B 中文操作说明

开始游戏后保持固定坐姿视角。左侧是透明抽屉和三个动物胶带架，左后方是悬挂贴纸，后方是内页与 TN 书架，右侧是三个便签盒。中央手账和前右方空桌面用于制作。

## 取胶带与操作轴杆

1. 左键点击抽屉把手，或按住把手沿前后方向拖动。抽屉充分打开后才能拿取里面的物品，再次点击或拖回可关闭。取下层物品时，先关闭上方抽屉，避免上层托盘挡住拿取路径。
2. 左键单击胶带卷可选择它并显示名称。需要搬运时，按住左键拖动卷体，或点击提示区的“取下选中胶带”。
3. 点击或侧向拖动动物架上的小黄铜轴杆把手，先抽出横轴。把胶带拖到空轴位附近松开，再推回轴杆。每轴只放一卷，三架互相独立。
4. 取下已安装胶带前先抽轴。选中胶带后按 `R`，或点击“R 放回原收纳位”，可送回原抽屉；对应抽屉需要保持打开。

卷体和轴杆把手执行不同操作。右键用于拉取胶带；取消使用 `ESC`。

## 拉取胶带并粘贴

1. 选中一卷胶带，点击右键，或点击“右键拉取 · 5 cm”。默认拉出 5cm。
2. 左右移动鼠标调整长度，范围为 2–30cm；侧栏实时显示厘米数。
3. 再次右键，或点击“确认撕取”，生成一段独立胶带。原胶带卷保留在原处。
4. 移动到中央手账页面或已打开的离型本页面，左键粘贴。`ESC` 取消当前操作。

胶带图案连续重复，长度变化不会把图案拉伸。放置时必须完整落在纸面内；超出边界会提示。可用 `Q` / `E` 主动旋转，`[` / `]` 主动缩放，或选择更合适的纸面。30cm 长条本身大于 A5 页面对角线，需要主动调整尺寸等条件后才能放置；系统不会悄悄缩小。记录会保留原裁切长度及当前缩放值。

## 贴纸、便签和内页

- 悬挂架上的贴纸均可取用；左键拿起后，移动到有效页面，再左键粘贴。也可拖到页面后松开。
- 三个小便签盒分别对应“复古书信”“自然花园”“简约日常”。从露出的便签单张取用，盒内静态便签叠会保留。
- 贴纸与便签可贴到手账或离型本，取消后恢复原来的安全位置。
- 内页架的八款纸张可拿到桌面、移动和归位；指向纸张可查看缩略图、风格、真实尺寸及装订信息。更换中央手账内页仍使用原编辑界面的“更换内页”；本次不模拟实际活页装订。

## 整理两本离型本

1. 关闭上面两层胶带抽屉，再充分拉开最下层透明抽屉，取出离型本 A 或 B，放到前右方空桌面。先放稳再打开；不能在抽屉里展开。
2. 单击放好的本子，或点击“打开离型本”。也可使用顶栏“离型本 A / B · 打开”。顶栏“← 上页”“下页 →”翻阅对应本子。
3. 胶带段、贴纸和便签可自由贴到离型本页面；位置和旋转不按网格排列。
4. 左键选中已贴素材，按 `P`，或点击“P 揭起并转移”；在离型本上也可按住素材拖动揭起。原页面立即腾出位置，素材跟随指针。
5. 将同一份素材贴到手账、同一离型本的另一页，或另一本已打开的离型本。失败或按 `ESC` 时恢复原处。转移不会复制物品。
6. 收起前点击对应本子的“合上”，再使用“拿起合上的本”或按 `R` 放回打开的抽屉。打开的本子不能直接归位。

两本离型本各有自己的页面和内容，正常退出后由存档保留。具体持久化验证结果见开发验收报告。

## 编辑、撤销与原有手账

- 选中素材后使用 `Q` / `E` 旋转、`[` / `]` 缩放；侧栏提供“置于底层”“置于顶层”“Delete 删除”。
- `Ctrl+Z` 撤销，`Ctrl+Y` 重做；`ESC` 取消当前拿取、拉取或转移。正在移动的物品应先完成放置或取消，再开始其他操作。
- 空手点击中央手账进入原有数字编辑，翻页、换纸、缩放、数字素材浏览和装饰编辑继续使用原来的按钮。原编辑中选中的装饰也可按 `P` 揭起转移。
- TN 书架上的本子可拿取和归位；鼠标指向 TN 后按 `E` 查看，按 `R` 归位。本次不提供 TN 换内芯。

操作提示会说明当前物品和可用动作。若没有合法放置位置，移动到空白桌面或有效页面，或按 `ESC` 安全恢复。

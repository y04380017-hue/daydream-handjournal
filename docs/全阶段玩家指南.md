# 白日梦手作房：全阶段 Demo 玩家指南

## 开始、旧存档与双人本机体验

双击项目根目录的 `开始白日梦手作房.cmd`，会先启动本机云上邮局，再打开游戏。主入口继续使用你原有的默认手账存档，不会换成空白新档。直接打开 `Build/Windows/VintageJournalDesk.exe` 也使用原存档，离线创作照常可用。

需要在同一台电脑体验好友交换时，双击 `打开第二位玩家.cmd`。这会使用独立的PlayerB存档；两个窗口各自在“云上朋友”注册身份，再用好友码邀请和接受，不会共用同一份手账。不要把同一份存档同时打开两次；启动工具会检查相同玩家是否已经打开。

本机邮局使用这台电脑已安装的Node.js，默认只监听127.0.0.1:18747；没有部署到互联网。首次启动如失败，可看 `SocialService/data/service-error.log`。程序本身可独立离线运行。

## 三时段、来信与收集

设置中可随时选择白天、午后或黑夜；素材袋里也有时段切换按钮。六位客户各有8章故事：白天、午后、夜晚各两位。每个时段先遇见一位朋友，累计3封回信达到声望2后，另外三位会开始来信；旧存档已经遇见的朋友不会重新锁住。读信里的诗意方向，自由表达；隐藏情绪匹配、布局与偏好只影响友善回信和回礼，每张非空作品都被接受。

点击桌后漂浮的泡泡、纸鹤、小云、散页、蒲公英、气球、叶片、金尘、萤火、近星或纸灯笼。每个时段独立积攒，初次3份，每约两小时补3份、最多6份，切换时段不会刷新奖励或让物品消失。偶有特别纹理、稀有材料与门/阶梯小事件。

打开素材袋取用，再左键贴进打开的手账或离型本。Q/E旋转、方括号缩放，ESC回原处。有限材料用一次就进入页面，揭取仍是同一份，不会复制。原有抽屉、轴杆、裁胶带、TN与离型本操作继续可用。

## 我的手账与创作工具

左下“我的手账 / 手作房”打开七个标签页。私人模式隐藏委托和分数，保留原活页本24页、所有旧作品与ID；TN与离型本仍各自独立。可选择封面材质、颜色、标题和挂饰，添加主题分区，收藏作品并按日期浏览。

“日记与分区”提供每天一条可选提示，也能真正输入并保存文字。不必连续登录，离开几天只会有温柔的问候和小礼，没有惩罚。

“创作工坊”有三种画笔、收集墨水调色板、256×256贴纸和白色刀模边缘；三种字体文字贴纸、印章也能保存为模板。模板可反复印制，每次取出的是新的独立材料；取消归还后再取用，会优先继续使用那份材料。工具随第1/2/3封回信逐步开放，也能用梦币兑换。

“拍照与分享”能导出带小标识的页面PNG、拍摄带滤镜的工作室照片，并制作拍立得素材。已完成委托照片独立归档，原作留在自己的本子里。导出路径显示在界面底部，文件位于当前存档旁的studio-exports目录。年鉴从真实收藏、素材与来信记录生成双页图片。

## 日常、成长与节庆

“日常与工房”有每日委托、材料图鉴、声望、工具和梦币购买。升级会在桌面新增独立3D小灯、陈列物与风铃；不会移动原收纳设施。真实日历决定季节材料与客串信件；同一份每日或季节礼物只领一次。

足迹页记录本机真实访问、会话、寄件、素材和图片导出次数，可导出不含日记正文或图片的CSV。留存率需真人样本和足够观察天数，界面不会编造D1/D7数据。

## 云上朋友与本机审核

连接和发布只发生在你主动点击后。画廊没有评论，可点赞；好友需互相接受，才能异步寄信或赠自制贴纸。玩家也能发布诗意委托，由另一位接单、制作页面照片并交稿。

所有文字、图片、礼物、委托与交稿先进入待审队列，审核通过才公开或寄达。在“本机审核”输入独立密钥后刷新并逐项通过/拒绝。密钥保存在 `SocialService/data/moderator-key.txt`，普通玩家身份不能代替审核身份。举报会先下架等待复核，也可屏蔽或暂停账号。

私人日记不会自动分享。收礼先保存再向邮局确认；掉线可重试，同一份礼物不会重复生成。请给不同本机玩家使用不同存档，保管好自己的匿名身份和服务数据；本机身份不是具有密码找回能力的正式线上账号。

## Demo 容量与验证范围

自制模板最多24份、好友图案最多12份，手账快照上限8MB，本机服务数据上限64MB。此版本用于完整流程试玩；公网部署、正式账号恢复和长期内容运营尚未进行。

实际通过的自动测试、原生操作、截图和仍需人工验证的部分，见 `全阶段开发验收报告.md`。操作结束会自动保存，退出前完成或取消手里的素材。

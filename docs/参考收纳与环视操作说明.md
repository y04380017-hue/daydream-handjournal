# 参考收纳与环视操作说明

## 打开离线 Demo

在文件资源管理器中打开 `E:\HandbookGameDemo\Build\Windows`，双击 `VintageJournalDesk.exe`，在开始页点击 **坐到桌前**。桌面创作、实体收纳、环视和漂浮素材领取可离线使用。

## 坐着环视与切换特写

- 在桌面近景中确认左侧显示 **环视：开**；若为关，点击开启。先把鼠标移回画面中间，再移到左右边缘。不用按住鼠标，停在边缘会持续向相应方向转头；移回中间便停止。视点始终保持坐姿，不会自由行走。
- 上下边缘可小幅抬头、低头。环视到侧面或身后时，可点击 **回到桌面** 返回正前方。
- 左侧 **视角：… ▾** 可切换设施总览、手账特写、左侧胶带架、右侧本册与便签、左抽屉、右抽屉。切换后等镜头停稳再操作。
- `ESC` 会优先关闭当前菜单或取消手里的操作；没有进行取放时，可从环视或设施特写返回桌面正前方。返回后先把鼠标移回中间，避免马上继续转头。
- 鼠标按键拖动、抽屉滑动、拉胶带和查看本子时，环视会暂停。若想专心整理，可把 **环视** 切到关。

## 选中、移动与归位

| 操作对象 | 操作方式 |
| --- | --- |
| 普通素材、笔、点点胶 | 左键单击选中，保持原位；按住右键拖到目标位置后松开 |
| 离型本 | 左键拖到桌面空位；放稳后右键单击打开 |
| TN和便签本 | 左键选中；右键单击拿起查看，右键拖动移动 |
| 抽屉把手 | 左键点击开合，或按住左键沿前后方向拖动 |
| 当前选中物品 | 按 `R` 返回原收纳位；抽屉中的物品需要先打开原抽屉 |
| 正在拿取或粘贴的素材 | 按 `ESC` 取消，查看界面提示确认恢复位置 |

打开的离型本应先合上，再归位。查看本子时，可以用界面翻页按钮、左右方向键或 `Page Up` / `Page Down` 翻看内页；`ESC` 退出查看。

## 布艺收纳包和本册

桌后中央的布艺收纳包有挂绳、布背板和 **8个小兜**，共收纳24张便签。小兜中的便签分层插放；取走前面的便签后，后面的便签会露出来。可切换近景查看图案，再右拖到打开的页面使用。

右侧书架保持7本侧插本册，书脊朝外。TN和便签本可以拿起查看内页，也可以通过本册操作面板放到中央工作。不同本册的内页各自保存。

## 小抽屉与叠层素材目录

两只桌下抽屉的外形缩小到此前的60%，素材仍保持原来的真实尺寸，因此部分材料采用叠层收纳。

- **左抽屉**：15卷备用胶带和8款内页，分别装在胶带盒、内页盒中。
- **右抽屉**：贴纸、便签补充包和6支笔，按盒分类收纳。

取用被上层遮住的材料时：

1. 在视角菜单选择对应抽屉，拉开抽屉。
2. 点击左侧 **抽屉素材目录 · 取出叠层素材**。
3. 在右侧目录切换分类、翻页，找到目标后点 **抽出取用**。
4. 等物品移到桌侧带有“取用”字样的薄荷色小垫，再选择、右拖或查看。需要归还时，选中它并按 `R`。

目录移动的是盒里的原物品，不会额外复制。取用垫一次放一件，抽下一件前会先归还上一件；若垫子被其他东西占住，会提示先移开。目录展开时，点击外面的空白处只会关闭目录，不会顺便抓起后面的物品。

内页可以抽出查看或右拖摆放；要更换中央手账的纸纹，请使用中央手账原有的 **更换内页** 菜单。

## 胶带柜、图案样条与离型本

浅木柜上方陈列 **30卷胶带**，左抽屉另有15卷备用。柜前垂下的图案样条用于看连续纹样；点击样条会选中对应的那一卷。

拉取胶带：

1. 从卷体或对应样条按住左键，向桌前拉拽。
2. 进入长度选择后，继续朝桌前或后方移动鼠标调整长度。默认5厘米，可选2–30厘米。
3. 右键单击或点击 **确认撕取**，再贴到打开的页面；`ESC` 取消。

如果要搬整卷，先抽出它的横轴，再横向右拖。图案样条本身不能作为第二份库存取走。

两本离型本归在木柜 **最低的开放层**。左键拖出，放到中央本子旁的空位，右键单击打开；可翻页、粘贴和揭取。拖动时会先从柜前抽出，再跟随鼠标移动；出口被挡时可移开前方物品，或按 `ESC` 取消退回。合上后按 `R` 可归回这一层。

## 物品介绍与漂浮素材

左键选择胶带、贴纸、便签或内页时，可看到图案介绍卡和围绕实物的光晕。关闭介绍卡不会消耗素材，选中本身也不会把物品抬起来。

领取额外素材时，先返回桌面正前方，结束手里的取放、关闭其他面板，再左键点击可领取的漂浮物。成功时会显示 **获得额外素材** 和素材名称，介绍卡会说明来源与图案；之后可从素材袋取用。

环视能看到的远景图画、装饰风筝、茶杯、箱子和其他背景摆设用于营造环境，不是每件都能领取。正面可领取物领取后会消失，不能反复点击同一件取得多份。

本说明记录本轮实现的操作入口；实际测试范围和结果以本轮验收记录为准。

# 委托信玩法说明

启动 `Build/Windows/VintageJournalDesk.exe`，或在 Unity 中打开 `Assets/Scenes/VintageJournalDesk.unity` 并按 Play，然后选择「坐到桌前」。

## 一轮流程（约 2 分钟）

1. **看邮筒**：桌子右后方悬浮着一个薄荷色邮筒。小旗竖起、上方飘着信封时，说明有新信。点击邮筒，或者点击左侧的「✉ 新信件」卡片。
2. **读信**：信里会写清楚这次想要什么感觉，比如「花草」「暖色」，以及至少要用几样素材。
3. **创作**：
   - 用抽屉和胶带架裁胶带：左键选中胶带，右键开始拉，再右键撕下。
   - 从悬挂架取贴纸，从便签盒取便签。
   - 贴到手账页上，或者贴到打开的离型本页面上。
   - 拿起素材时，面板会自动收起成清单卡；贴上带对应主题的素材，清单会实时打勾。
4. **寄出**：用 `‹ ›` 选择要寄的页面，点「拍照寄出」。寄出的是照片，作品会留在你的本子里。
5. **收回信**：几秒后会来下一封信；约 25 秒后收到回信和邮票。回信的照片会挂到书桌上方的明信片晾绳上。

## 小规则

- 没有失败：标签不匹配也能寄出，只是回信的语气不同，邮票数量也不同（✦ 收到 / ✦✦ 喜欢 / ✦✦✦ 心动）。
- 同一页原样不能寄两次。换一页，或者在原页上再添点东西就可以。
- 邮筒里最多同时有 3 封待回应的信。前 7 封是剧情信，之后会一直有新的委托。
- Ctrl+Z / Ctrl+Y 只撤销 / 重做素材操作，不会撤回已经寄出的信。

## 改内容

信件、寄信人、标签和节奏参数都在 `Assets/Resources/Commissions/commission-catalog.json` 里：

- `tags` 定义每个素材的主题。
- `letters` 是剧情信。
- `occasions`、`senders`、`tagPairs` 用来生成后续的委托。
- `replyDelaySeconds` 等字段控制节奏。

修改后重新进入 Play 即可生效。

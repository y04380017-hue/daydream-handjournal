# 自由拼贴系统架构

沿用原场景、DeskCamera、JournalController、独立左右页坐标和版本1存档。不重新生成既有图片或模型。

| 模块 | 职责 |
|---|---|
| DecorationCatalog / DecorationCatalog.asset | ScriptableObject定义资源ID、类别、缩略图、纹理、默认尺寸、缩放范围、长度能力、Alpha命中掩码 |
| ScrapbookController | 操作状态、页面归属、添加/变换/删除/图层事务、历史和保存协调 |
| ScrapbookInput | 真正的鼠标键盘输入、页面射线、Alpha选择、拖动与控制柄 |
| ScrapbookUI | 浏览、可用状态、轻量控制框和工具面板；屏蔽原工具栏下方的页面命中 |
| DecorationGeometry | 物理页面单位中的旋转、命中和完整旋转边界限制 |
| DecorationRenderer | 逐个运行时Mesh/材质、透明预览、接触阴影、图层深度与UV重复 |
| DecorationHistory | 按pageId隔离的60步命令快照；完整拖动只记录一次 |
| DecorationSaveQueue | 主线程验证/序列化，后台单写入者、最新待保存状态合并与相同内容去重 |
| JournalSaveService | 纯文件提交、版本兼容、备份恢复、序号防旧快照覆盖 |
| ScrapbookSetup | 向现有OpenJournal和NoteBox接线，不重建桌面 |

## 坐标和大小

position是页面归一化中心坐标。size是归一化基础尺寸，scale为统一缩放系数，length为胶带长度倍数。旋转、命中和边界计算先转换到纸张物理宽高（约0.393×0.52米），所以不会把长方形页面当成正方形旋转。完整旋转矩形限制在单页内；拖动不会把实例的所属页变成另一页。

视觉对象挂在JournalPageView的左右独立Transform下，镜头变化不改存档坐标。透明PNG由离线CPU生成的64×64 Alpha掩码辅助选择，不在运行时读取不可读纹理。控制框对极小素材保留最小屏幕间距，避免删除、缩放与长度柄重叠。

## 状态和输入

Idle / BrowsingAssets / Placing / Selected / Dragging / Rotating / Scaling / PageTurning / Transitioning。

编辑素材时阻止翻页和镜头操作；空闲时沿用原镜头滚轮和平移。ESC逐级取消当前操作，用同帧消费标记防止一次ESC同时取消素材和退出手账。桌面收纳仍使用原DeskUI，真实点击缩略图可进入待放置；编辑内浏览使用左侧轻量面板。

## 胶带和排序

胶带使用原Textures/Tapes/*_pattern.png，按物理长度/宽度计算UV重复。材质具有真实透明度、纤维边缘与轻微闪砂；排序同时使用显式透明队列及微小页面法线偏移。图层操作限定在同一页，顺序写入sortOrder。

## 保存与旧档

schemaVersion仍为1：第二阶段已预留decorations，本阶段添加pageId、size、length，不改变原页面/内页ID。缺失字段安全补齐；旧形态没有实例ID的记录获得稳定的legacy ID；未知素材、类型和扩展payload保留。已识别素材的旧边缘/超大记录在显示前修正到有效纸面范围，不删除旧记录。

操作提交后主线程只生成不可变JSON，后台仅执行.NET/Win32文件操作，不访问Unity对象。只有一个活动写入和一个最新待写快照。翻页前Flush，退出和显式Save保持同步完成语义，相同内容不重复做磁盘I/O。后台故障保留待写状态供显式重试，不每帧反复写坏盘。

普通文件系统优先临时文件原子替换。本机加密目录的兼容提交保留上一版字节完整备份，读取失败时保留broken文件并恢复；兼容路径仍不保证断电瞬间完全原子。测试存档独立在Stage3Validation，不修改普通玩家作品。

新增素材可在DecorationCatalog.asset追加完整定义，不需修改拖拽代码。主动运行目录重建菜单会从旧商品JSON重新登记素材，手工追加前应保留定义或同步资源清单。正常Play不重建资源。
